# Time-Cost 데모 (Android)

PRD v0.1 12장 개발 순서 진행 상황.

- [x] 1단계: 프로젝트 골격 · 테마 · 내비게이션 · Room · AppClock · 시드 · 홈 목록
- [x] 2단계: 구독 추가(F2·F3) · 구독 상세(F4) · 앱 선택(F11) · 사용 시간 읽기(Real·Fake)
- [x] 3단계: 결정 흐름(F6) · 사용 시간 수정(F5) · 종료 알림(F3-5)
- [x] 4단계: 계산기 · 통계 · 휴지통 · 설정(F7~F10)
- [x] 5단계: 시연 도구(F12) · 시나리오 A~F 리허설 · 접근성 점검 (REHEARSAL.md)

## 열기
Android Studio에서 이 폴더를 열고 Gradle Sync → 빌드 변형 `demoDebug` 실행.
`gradle/libs.versions.toml`의 버전은 열 때 최신 안정 버전으로 올려 주세요.

## 메모
- 데모 빌드는 기준일을 2026-11-10으로 고정하고 가상 사용 데이터·가상 앱 목록을 씁니다.
- prod 빌드의 RealUsageSource는 '사용 정보 접근' 허용이 필요합니다. 안내는 설정(F10-2)과 홈·상세의 사용 시간 영역에 있습니다.
- 시스템은 일 단위 사용 기록을 약 7일만 보관하므로, 그보다 오래된 날은 '기록 없는 날'로 저장합니다(추정하지 않음).

## 3단계에서 정한 사항 (PRD 14장 열린 질문)
- 질문 3: 체험의 '종료 후 구독료'가 비어 있으면 확인 시트 대신 수정 화면으로 바로 이동합니다.
- 질문 4: 새 구독은 평소 정렬 위치에서 3초간 하이라이트하고, 화면 밖이면 그 위치로 스크롤합니다.
- 질문 5: 종료 알림은 WorkManager(정확 알람 권한 없음)로 예약하고, 화면 문구는 '오전 9시경'처럼 씁니다.
- 데모 빌드는 기준일이 가상이라 알림을 실제로 예약하지 않습니다. 가상 예약 목록과 테스트 알림은 5단계 시연 도구(F12)에서 보여 줍니다.

## 4단계에서 정한 사항
- PRD 14장 열린 질문 1(1시간당 비용 표시): 홈 카드에는 표시하지 않고, 통계에서만 보여줍니다. 이번 결제 기간은 아직 진행 중이라 사용 시간이 늘면 값이 줄어든다는 안내를 붙였고, 지난 결제 기간이 없으면 '지난 결제 기간이 아직 없어요'로 표시합니다.
- 다음 결제: 무료 구독은 결제가 없어 제외하고, 같은 날이면 금액이 큰 쪽을 보여줍니다.
- 휴지통: 보관 30일이 되는 날 앱을 열 때 자동 완전 삭제합니다(남은 일수는 1일 이상만 표시).
- 데모 빌드의 사용 정보 접근은 가상 데이터를 쓰므로 '허용됨'으로 표시합니다(권한 없음 재현은 5단계 시연 도구).

## 5단계에서 정한 사항
- 데모 모드 전환(F12-1)은 DB와 시계를 앱 시작 때 정해야 해서 SharedPreferences에 저장하고, 전환하면 앱을 다시 시작합니다. 끄면 실사용 DB와 실제 날짜를 씁니다.
- 기준일을 앞으로 옮기면 그 사이 날들의 가상 사용 기록을 만들어, 통계의 값이 날짜를 따라 바뀝니다.
- 시안(Adj1~3)과 맞추려고 시드의 YouTube Premium 시작일을 10월 9일로 두었습니다(다음 결제일 12월 9일 D-29는 그대로). 지난 결제 기간에 11월 8일(자동 50분)·11월 7일(기록 없음)이 들어갑니다.
- 가상 예약 알림 2건(시안)을 맞추려고 종료 알림은 Apple Music과 Disney+만 켜 두었습니다.
- 시연 시나리오 B~F는 PRD에 시안이 없어 제안안으로 정했습니다(ScenarioTest, REHEARSAL.md).
