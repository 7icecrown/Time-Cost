# Time-Cost

**구독료를 사용 시간으로 환산해 구독 서비스의 실질적인 가치를 확인하는 Android 앱입니다.**

Time-Cost는 구독 서비스의 지출과 사용량을 함께 관리하여, 사용자가 자신의 구독 소비를 쉽게 파악하고 무료 체험이나 할인 기간이 끝나기 전에 유지 여부를 결정할 수 있도록 돕습니다.

## 주요 기능

- **구독 관리**: 정기 구독과 무료 체험·할인 내역 등록 및 관리
- **사용 시간 기록**: 연결한 앱의 사용 시간을 기록하고 필요하면 직접 수정
- **시간당 비용 계산**: 구독료와 사용 시간을 바탕으로 1시간당 비용 계산
- **구독 통계**: 월간 구독료, 연간 예상 지출, 서비스별 지출 비중 확인
- **종료 알림**: 무료 체험과 할인 기간의 종료 일정 관리
- **유지·해지 결정**: 종료 시점에 구독 유지 또는 해지 여부 기록
- **휴지통**: 삭제한 구독 복구 및 완전 삭제

## 기술 스택

| 구분 | 기술 |
|---|---|
| 언어 | Kotlin |

| 화면 이동 | Navigation Compose |

## 실행 방법

Android Studio에서 프로젝트 루트 폴더를 열고 Gradle Sync를 진행합니다.

- JDK 17 이상
- Android SDK Platform 35
- Android SDK Build-Tools 35.0.0

빌드 변형에서 `demoDebug`를 선택하면 시연용 앱을 실행할 수 있습니다.

자세한 빌드 방법은 [BUILDING.md](BUILDING.md)를 참고하세요.
